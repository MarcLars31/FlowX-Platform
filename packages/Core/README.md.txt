# FlowX Core

FlowX Core is the domain heart of the FlowX Platform.

It contains the engineering knowledge, rules, validation, calculation logic and product selection logic used by the platform.

## Core Responsibilities

FlowX Core owns:

- Knowledge Engine
- Rule Engine
- Calculation Engine
- Validation Engine
- Product Engine

## Core Rules

FlowX Core must not depend on:

- frontend frameworks
- web APIs
- databases
- PDF generation
- Excel export
- external services
- AI providers

FlowX Core must be deterministic, testable and technology independent.

## Purpose

The purpose of FlowX Core is to transform engineering knowledge into reliable software behavior.

Core is the most valuable technical asset in the FlowX Platform.
